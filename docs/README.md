## Описание сервиса

Модели:

| Модель                 | Описание                        |
|------------------------|---------------------------------|
| `User`                 | данные пользователя             |
| `UserOrder`            | зказ пользователя               |
| `UserBalance`          | баланс пользователя             |
| `UserBalanceWithdrawn` | списание с баланса пользователя |

Сервисы:

| Сервис               | Описание                                                        |
|----------------------|-----------------------------------------------------------------|
| `UserService`        | сервис управления пользователями, добавлением, проверкой проля  |
| `UserBalanceService` | сервис управления балансом пользователя, списанями              |
| `UserOrderService`   | сервис управления заказами пользователя, регистрация заказов    |
| `PasswordService`    | сервис реализующий работу с паролями, хэширование и проверка    |

Связт с внешним сервисом:

| Интерфейс        | Описание                       |
|------------------|--------------------------------|
| `AccrualAdapter` | адаптер к api внеднего сервиса |

Асинхронное взаимодействие:

| Элемент               | Описание                                                                                                                                                     |
|-----------------------|--------------------------------------------------------------------------------------------------------------------------------------------------------------|
| `requestProducer`     | поставщик канала заказов поступающий по http запросу на метод резистрации заказа пользователя                                                                |
| `retryProducer`       | поставщик канала заказов поступающих после их обработки, для отложенной повторной обработки                                                                  |
| `setupProducer`       | поставщик канала заказов из базы данных при старте сервиса, которые ещё не были обработаны                                                                   |
| `jobProducer`         | поставщик канала заказов на обработку для обработчиков, объединяет каналы остальных поставщиков                                                              |
| `workerHandler`       | обработчик канала заказов, запукает обработку несколькими обработчиками                                                                                      |
| `OrderIDWorker`       | обработчик заказа, проверяет статус и возраграждение за заказ в внешней системе расчета возраграждений и передаёт результат в канал результатов              |
| `resultCh`            | канал результатов, служит для передачи результата от обработчиков к дальнейшей их обработке                                                                  |
| `resultHandler`       | обработчик канала результатов, запускает обработку несколкьими обработчиками                                                                                 |
| `OrderIDResultWorker` | обработчик результата обрбаотки заказа, сохраняет новый статус обработки заказа, начисляет возрагроаждение, передаёт заказ на отложенную повторную обработку |
